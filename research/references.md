# Visual reference board

The reference pass that informed the treatment (see `../design.md`). One note per body of work —
_what works · what doesn't · what to steal · what NOT to copy_. The architecture stayed frozen; this
was about visual intelligence. Balance: **cartography → composition · editorial infographics →
hierarchy · aerospace → technical language · Singapore design → restraint · interaction →
exploration** — a blend, not "NASA-style."

## Systems / ecosystem maps

- **Works:** concentric layouts encode distance/influence (inner = direct, outer = indirect); stroke
  varies by relationship type.
- **Doesn't:** the common "label the flows (money/authority)" advice over-claims.
- **Steal:** concentric layers; pathway/confidence strokes.
- **Don't copy:** flow labels — we depict only _evidenced_ relationships.
- Refs: OpenLearn systems maps; IxDF ecosystem maps; Design Council systemic design.

## Information graphics — Halcyon "Map of the Internet"

- **Works:** makes thousands of intangibles parseable via named clusters/regions + visual hierarchy
  for prominence + methodology shown alongside.
- **Doesn't:** a literal geography metaphor would imply false spatial meaning.
- **Steal:** named capability groupings; focal hierarchy; method-visible.
- **Don't copy:** the country metaphor; prominence-by-popularity (we use _editorial_ prominence).
- Ref: WEF feature on the Halcyon map.

## Aerospace — NASA / ESA architecture diagrams

- **Works:** "convey information with a minimum of explanation; every diagram carries a legend";
  disciplined colour-by-role.
- **Doesn't:** SysML / enterprise-framework density is illegible to a public audience.
- **Steal:** always-present self-teaching legend; minimum-explanation; disciplined role colour.
- **Don't copy:** SysML density; let aerospace inform _language_, not dominate the style.
- Refs: NASA SWEHB 7.7; ESA Architecture Framework.

## Cartography

- **Works:** legibility · contrast · figure-ground · hierarchy · proportion; figure-ground via
  contrast/contour/area/enclosedness; labels on the top visual plane; "spatialization" legitimises
  non-geographic maps.
- **Doesn't:** decorative geographic cues (fake north arrows, real-looking coordinates).
- **Steal:** network = figure, construction = ground; labels on top; explicit hierarchy levels.
- **Don't copy:** anything implying real geography.
- Refs: Esri cartographic design principles; Wikipedia figure-ground.

## Interaction — Shneiderman

- **Works:** "overview first, zoom and filter, details on demand"; linked views (select in one →
  highlight in others).
- **Steal:** overview → select → highlight → inspect → return; **link map ↔ catalogue** highlighting.
- **Don't copy:** feature-for-feature dashboards.
- Ref: Visual Information-Seeking Mantra.

## Singapore design

- **Works:** "authentically Singaporean" = values (pragmatism, order, restraint), not motifs;
  distilling to fundamentals; designs that don't require much explanation — suited to national
  projects with many stakeholders + international audiences.
- **Steal:** restraint as the signature; minimum-explanation.
- **Don't copy:** flags, Merlions, red-and-white everything.
- Ref: DesignSingapore Council.

## Failure modes (design against)

- Hairball (too many edges, no pattern); over-labelling; rainbow colour; unexplained edge semantics;
  too much on screen at once.
- **Mitigations in the Atlas:** documented-only at rest + progressive disclosure; labels for
  hubs/hover + shortest-alias + tertiary muting; disciplined 7-type palette + neutral edges;
  explicit pathway/confidence + permanent legend; focal hierarchy; corpus veto on decoration.
- Ref: "Grooming the hairball" (network-viz tidying).
